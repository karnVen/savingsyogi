## 🚀 The Mission

**Financial literacy in India is broken.**
Most platforms are either too complex (trading apps) or too generic (news sites). Young professionals lack a trusted, actionable guide to move from "saving" to "wealth creation."

**SavingsYogi** bridges this gap. We combine **mindful finance principles** with **data-driven tools** to help users navigate debt, build emergency funds, and master passive income strategies.

---

## ✨ Key Features

### ⚡ Zero-Load Interface
Powered by **React + Vite** and optimized with custom **GSAP** preloaders, the site feels instant. We prioritize "perceived performance" to keep users engaged.

### 🧠 Headless Content Engine
Built on **Sanity.io**, our content architecture is decoupled from the code. This allows our marketing team to push updates, blogs, and financial tips instantly without needing a developer deployment.

### 📱 Mobile-First Design
India is a mobile-first economy. The UX is natively designed for modern form factors (iPhone 12/14 Pro & Android flagships) to match our core demographic's browsing habits.

### 🧘 Mindful Finance Tools
We don't just show numbers; we address behavior.
* **The 24-Hour Rule:** Psychological friction tools to curb impulse spending.
* **Debt Snowball:** Visual guides for eliminating liabilities.

## 🛠️ Tech Architecture

Built for speed, scalability, and SEO dominance.

| Layer | Technology | Why We Chose It |
| :--- | :--- | :--- |
| **Frontend** | **React.js + Vite** | Sub-second load times and superior modularity. |
| **Styling** | **Tailwind CSS** | Rapid UI development with a consistent design system. |
| **CMS** | **Sanity.io** | Headless architecture for real-time content delivery. |
| **Animation** | **GSAP** | Premium, app-like feel with smooth micro-interactions. |
| **Deploy** | **Vercel** | Serverless global deployment with 99.9% uptime. |

## 🚀 Getting Started

To run the development environment locally:

1.  **Clone the Repository**
    ```bash
    git clone [https://github.com/karnVen/SavingsYogi.git](https://github.com/karnVen/SavingsYogi.git)
    ```
2.  **Install Dependencies**
    ```bash
    cd SavingsYogi
    npm install
    ```
3.  **Run Local Server**
    ```bash
    npm run dev
    ```
